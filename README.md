# Ambient Focus Studio (環境音ミキサー & 作業空間)

雨音やカフェ音、環境音を自由に組み合わせて作業・勉強に集中できるミニマルなWeb環境音ミキサーアプリです。

## 🌟 特長
- **ギャップレス音源再生**: 音声ファイルの切れ目がなく自然にループ再生されます。
- **音源追加・差し替え & 削除**: お好きなMP3/WAVファイルをブラウザ上に永久保存・追加・削除可能です。
- **組み合わせ保存・管理**: お気に入りの音量ミックスを保存し、いつでもワンタップで再現・削除が可能です。
- **ポモドーロタイマー & タスク管理**: 25分作業・5分休憩のタイマーや目標管理機能を搭載しています。
- **100% クライアントサイド動作**: サーバー不要で完全無料で動作し、データの外部送信も行われません。

## 🚀 GitHub Pagesでの公開方法
1. このリポジトリをGitHubにプッシュします。
2. GitHubリポジトリの **Settings** > **Pages** を開きます。
3. **Source** を `Deploy from a branch` に設定し、`main` ブランチを選択して **Save** を押します。
4. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` にてWebアプリとして公開されます！
